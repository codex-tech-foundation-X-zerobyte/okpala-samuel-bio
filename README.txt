HOW TO PUBLISH THIS SITE

1. Buy your domain (for example okpalasamuel.com).
2. In index.html, robots.txt, sitemap.xml and llms.txt, search and replace
   YOURDOMAIN.com with your real domain (no https://, just the name).
3. Host the folder on Cloudflare Pages, Netlify or Vercel (drag and drop the
   folder), then connect your domain.
4. Add the site to Google Search Console and Bing Webmaster Tools and submit
   https://YOURDOMAIN.com/sitemap.xml
5. Link to the site from your LinkedIn, X, GitHub and other profiles, and add
   those links to the Person data (sameAs) in index.html.

FILES
index.html   page content (each section has a comment saying what it is)
styles.css   all design: colours at the top (:root), phone layout at the bottom
script.js    mobile menu only
photo.jpg    your portrait; replace it with a new file of the same name
robots.txt, sitemap.xml, llms.txt   for search engines and AI tools
